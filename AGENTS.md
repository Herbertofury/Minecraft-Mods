## Minecraft Mods local research contract

- This repository is the Minecraft mod research catalogue, not a mod implementation or proof of compatibility. Start with README.md and the relevant docs/ source observations, catalogue and import receipts.
- Preserve stable identities, attached observations, favorites, provenance, unresolved rows and dated verification scope. Similar names, loader branches, editions, world DLC, resource packs and actual mods are not interchangeable. Do not merge identities without evidence or erase unsuccessful/unknown checks.
- Keep discovery, curated recommendations, implementation targets and native gameplay acceptance separate. Official listing identity and historic receipts do not certify current compatibility. Do not invent a test command; this checkout has static catalogue/documents rather than an executable test suite.
- Research/UI/catalogue features should cooperate through stable data contracts without making one favorite ecosystem a prerequisite for unrelated content. Keep project-specific domain rules here, not in Agent-Foundry's core.
- Review data preservation and local links when changing catalogue content. Website/wiki publication must be checked separately from repository files. Never redistribute paid/proprietary mods, credentials or personal game data.
