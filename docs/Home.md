## Current import coverage

The first import contains **1,593 source records**, reconciled into **1,497 research entries**. 96 repeated source rows were merged by exact project routes while preserving their notes. 306 entries are discovery routes rather than confirmed installable mods. This is not a count of unique, tested mods.

Two source catalogues are imported. The remaining indexed collections, unique update notes, HTML and Google Docs are still being reconciled. Original files remain intact. Version claims copied from a source are distinguished from newly checked official releases and native testing.
