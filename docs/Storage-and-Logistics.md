## Build around complementary roles

- **Physical bulk + digital access:** research Storage Drawers with AE2, then qualify adapters and storage ownership in the exact pack.
- **Visible storeroom + searchable access:** investigate shelf/chest storage with a simple network and item-location tools.
- **Factory logistics + local containers:** evaluate pipes or Create logistics with storage suited to the build. Qualify the actual Create branch; a feature showcase does not establish support on every version.
- **Inventory convenience:** select complementary sorting, transfer and search tools. Test shared keybinds, custom screens and server rules rather than stacking overlapping automation blindly.
- **Performance companions:** pin the relevant parent release, test one change at a time and measure the same workload. An optimizer label or editorial score is not benchmark evidence.

## Preserve the forever world

Before upgrades or removal, test a copied world with named/damaged/enchanted items, custom stack data, nested storage, chunk unload/reload, save/restart and automation endpoints. Verify item counts and configuration survive. A client-only claim still needs target-server and UI testing; it does not imply every multiplayer policy permits automation.
