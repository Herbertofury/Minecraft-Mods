## Current import coverage

The first import contains **1,981 source records**, reconciled into **1,814 research entries**. 167 repeated source rows were merged by exact project routes while preserving their notes. 306 entries are discovery routes rather than confirmed installable mods. This is not a count of unique, tested mods.

Three source catalogues are imported, including creature-variety research. The remaining indexed collections, unique update notes, HTML and Google Docs are still being reconciled. Original files remain intact. Version claims copied from a source are distinguished from newly checked official releases and native testing.

The expanded Forever World roster brings the live catalogue to **1,829 research entries and 42 favorites**, including 39 owner-selected target observations. Targets without a resolved release route remain visibly labeled compatibility targets.
